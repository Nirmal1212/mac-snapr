Second build of the first public beta of Snapr, a free macOS menu bar app for Windows-style window snapping. Please try it and report what breaks.

## Install
1. Download `Snapr-0.1.0-beta.2.dmg` below, open it and drag Snapr to Applications.
2. This beta is **not notarized**, so macOS blocks the first launch:
   - macOS 13/14: right-click Snapr.app and choose Open.
   - macOS 15 and later: try to open it, then go to System Settings > Privacy & Security and click "Open Anyway".
   - Or run `xattr -dr com.apple.quarantine /Applications/Snapr.app`.
3. Grant Accessibility access when prompted (System Settings > Privacy & Security > Accessibility). Snapr cannot move windows without it.

Requires macOS 13 (Ventura) or later, Apple silicon or Intel.

## What to try
- Click the menu bar icon for the intro, then "Show all options".
- Snap the focused window with Ctrl+Opt+Arrow (halves), U/I/J/K (quarters), D/F/G (thirds); drag a window to a screen edge or corner.
- Settings (sidebar with search): shortcuts, gaps, layouts, multi-window tile/cascade, custom zones, ignored apps.

## Known issues and limits
- **Re-grant Accessibility after updating.** Beta builds are signed ad hoc, so macOS treats each new build as a different app. If snapping stops working after an update, remove Snapr from the Accessibility list and add it again, or run `tccutil reset Accessibility com.you.snapr` and relaunch.
- The bundle identifier is still a placeholder (`com.you.snapr`) and will change before 1.0, which will also need a fresh Accessibility grant.
- Much of the OS-facing code (Accessibility window control, hotkeys, drag snapping, popover, settings UI) has had only light manual testing. Expect rough edges, especially with multiple displays, Stage Manager and unusual apps.
- Moving windows between Spaces is experimental, off by default, and uses private macOS APIs.
- No automatic updates in this beta; download new betas from this page.
- Light and dark appearance have not been systematically checked.

## Privacy
Everything runs locally. No telemetry, and no network access in this beta.
