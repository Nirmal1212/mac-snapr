## Why
macOS lacks built-in, keyboard-driven window snapping comparable to Windows (Win+Arrows, edge-drag snap). Users rely on heavy third-party tools. A minimal native utility fills this gap.

## What Changes
- Window snapping to halves, quarters, thirds, maximize, center, restore
- Configurable global keyboard shortcuts
- Move windows between displays
- Drag-to-edge snapping with preview overlay
- Menu bar app with settings and Accessibility onboarding

## Impact
- Affected specs: window-snapping, keyboard-shortcuts, multi-display, drag-snapping, menu-bar-app (all new)
- Affected code: new app; no existing code
